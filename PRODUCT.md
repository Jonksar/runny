# Product

## Register

product

## Users and purpose

Developers talking to a Codex coding agent from a phone while running. A successful session carries speech in both directions, delegates coding work, and reports real results without requiring screen attention.

## Voice and references

Direct, compact instructions. The README uses Hermes Agent as a reference for dense setup documentation. Preserve the existing dark phone interface and large control.

## Design principles

One prominent Start/Stop action. Show connection progress and retain useful failures. Keep code and settings out of the spoken flow. Use text alongside state colors, visible keyboard focus, and large touch targets. Do not imply a locked phone or real phone call is supported without device evidence.
